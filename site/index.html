Columns the contracts file needs

Export active contracts or deals from your CRM, or keep them in a Sheet, as CSV with one row per contract. Use these column names, or download the template. If your file names a column differently, you match it after choosing the file.

Slash dates are read as US (MM/DD/YYYY) unless the file shows they are day first, and you can choose when matching columns. ISO dates (2026-10-16) and "Oct 16, 2026" also work.

      Make it run itself

      A Google Apps Script with the same aging, tiers and templates as this page (it's the same code). Every 14 days it reads the invoice export in a Sheet, saves one Gmail draft per customer for you to review (replacing last run's drafts you didn't send), and posts the summary to Slack. Nothing sends without you.

      1. Paste the invoice export into a Google Sheet, in a tab named Invoices, headers in row 1.
      2. Open Extensions › Apps Script, replace the contents of Code.gs with the script below, and save.
      3. In Project Settings › Script properties, add SENDER_NAME, SENDER_ROLE, FOUNDER_NAME, FOUNDER_ROLE and, optionally, a Slack incoming webhook as SLACK_WEBHOOK_URL.
      4. Run setup once and grant access to Sheets, Gmail and external requests. It adds a trigger for every other Monday at 8am.
      5. Run run once to check: drafts land in Gmail, the summary posts, and an AR runs tab logs the totals.
